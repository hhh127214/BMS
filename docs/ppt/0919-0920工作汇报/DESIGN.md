# DESIGN.md — 0919-0920 工作汇报（精简版 · 10 页）

## 项目元信息

- **项目目录**：`docs/ppt/0919-0920工作汇报/`
- **输出文件**：`0919-0920工作汇报.pptx`
- **目标受众**：听汇报的管理/协作方——**不讲代码与实现原理**，只讲工作、做法、结果
- **页面总数**：10 页（不设章节扉页——10 页不需要过渡页撑结构）
- **风格定位**：通用设计（工作总结，不命中学术/咨询/政务分支）。调性 = 工程严谨 + 证据驱动：
  克制留白、数据锚点大而清楚、**不使用摄影/插画/3D 装饰图**。
- **与详版关系**：视觉体系与 `0919-0920交付汇报/`（24 页详版）保持一致——同一工程、同一受众，
  色彩/字体/母版直接沿用，页面映射表全部重写。

## 1. 画布与母版

- **画布**：1280×720，固定。
- **母版（A/B/C 三区）**：
  - **A · 标题块**：0–120px（含上 padding 20px）；主标题 36px bold，副标题 18px regular（次色）
  - **B · 内容区**：120–660px，可用 540px；左右 padding 各 64px
  - **C · 页脚条**：660–720px；左侧项目名「工商业储能 EMS · 0919-0920 工作汇报」14px 次色，
    右侧页码 `NN / 10` 14px 次色
- 封面 P01 与结尾 P10：省略 C 区、自定义居中版式；P02–P09 严格一致。

## 2. 色彩系统

| 角色 | hex | 用途 |
| :--- | :--- | :--- |
| 背景 | `#FFFFFF` | 全篇底色 |
| 主色 | `#3B82F6` | 标题强调、图表主线、卡片头部、表头底 |
| 辅色 | `#06B6D4` | 次系列、09-20 组标记、正向证据 |
| 强调色 | `#EF4444` | **仅**用于：缺陷/风险/阻塞、核心锚点数字（9304、+1219）、反证与警示 |
| 文本主色 | `#1A1A1A` | 标题与正文 |
| 中性次色 | `#64748B` | 副标、注释、页脚、表格次要列 |
| 中性背景 | `#EFF6FF` / `#F1F5F9` | 卡片浅底、表格斑马纹 |

> 功能色 3 个（主/辅/强调）+ 背景 + 2 中性色，符合 ≤4 hex 约束。

### 2.1 色彩面积分配

| 页面类型 | 主色 | 辅色 | 强调色 | 留白 |
| :--- | :--- | :--- | :--- | :--- |
| 封面 P01 / 结尾 P10 | ≤ 25% | ≤ 10% | ≤ 8% | 45–55% |
| 数据高潮页 P02 / P07 | ≤ 30% | ≤ 18% | 12–18% | 25–35% |
| 内容页（其余 supporting） | ≤ 35% | ≤ 20% | ≤ 5% | 18–28% |

**色彩节奏**：强调色只出现在 P01（+1219）、P02（09-20 组的新增断言）、P07（9304 锚点）、
P08（缺陷栏）、P09（阻塞行）；P03–P06、P10 为 0 或近 0——「红 = 值得停一下」的语义不稀释。

### 2.2 渐变与半透明

- 允许：`linear-gradient(135deg, #3B82F6 0%, #06B6D4 100%)` 用于封面色带与卡片头部细条；
  `rgba(59,130,246,0.06)` 作表格斑马纹与浅底区间。
- 不使用多于一层的阴影；不在同一元素混用渐变 + 阴影。

## 4. 信息密度门禁

- 内容页：正文 ≥ 150 字 / ≥ 1 主视觉或图表 / 留白 ≤ 28%
- 数据页（P02/P07）：主图或主表占 B 区 ≥ 50%，配 ≥ 1 句结论
- 封面 / 结尾：留白 45–55%，但必须围绕焦点元素
- 卡片填充率 ≥ 85%；横向兄弟卡三段（标题/正文/尾条）y 轴对齐
