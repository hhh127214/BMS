# DESIGN.md — 0919-0920 两天交付汇报（测试 · 仿真 · 原理）

## 项目元信息

- **项目目录**：`docs/ppt/0919-0920交付汇报/`
- **输出文件**：`0919-0920交付汇报.pptx`
- **目标受众**：混合 —— 无理论储备的管理/协作方 + 能读架构与断言的工程师
- **页面总数**：24 页（4 章）
- **主题边界**：只讲 **2026-09-19 ~ 09-20 这两天**的交付，不做项目整体科普
- **风格定位**：通用设计（不命中学术 / 咨询 / 政务三个预设分支）。调性取自"工程严谨 + 证据驱动"：
  克制留白、数据锚点大而清楚、**不使用摄影 / 插画 / 3D 装饰图**。

## 1. 画布与母版

- **画布**：1280×720，固定。
- **母版（A/B/C 三区）**：
  - **A · 标题块**：0–120px（含上 padding 20px）；主标题 36px bold，副标题 18px regular（次色）
  - **B · 内容区**：120–660px，可用 540px；左右 padding 各 64px
  - **C · 页脚条**：660–720px；左侧项目名「工商业储能 EMS · 0919-0920 两天交付汇报」14px 次色，
    右侧页码 `NN / 24` 14px 次色
- 封面 / 4 个章节过渡页 / 结束页：省略 C 区或改自定义版式（其余页严格一致）。

## 2. 色彩系统

| 角色 | hex | 用途 |
| :--- | :--- | :--- |
| 背景 | `#FFFFFF` | 全篇底色 |
| 主色 | `#3B82F6` | 标题栏、图表主线、卡片头部、结构块 |
| 辅色 | `#06B6D4` | 次系列、章节锚点、光伏/收益类数据 |
| 强调色 | `#EF4444` | **仅**用于：越限/风险、核心锚点数字（734、9304）、判据反证与警示框 |
| 文本主色 | `#1A1A1A` | 标题与正文 |
| 中性次色 | `#64748B` | 副标、注释、页脚、坐标轴 |
| 中性背景 | `#EFF6FF` / `#F1F5F9` | 卡片浅底、区间带 |

> 色板共 4 个功能色（主/辅/强调 + 背景）+ 2 个中性色，符合"≤4 hex"约束（中性色不计入功能色）。

### 2.1 色彩面积分配

| 页面类型 | 主色 | 辅色 | 强调色 | 留白 |
| :--- | :--- | :--- | :--- | :--- |
| 封面 P01 | ≤ 30% | ≤ 12% | ≤ 5% | 45% |
| 章节扉页 P03/P07/P12/P19 | ≤ 20% | ≤ 15% | 0% | 60% |
| 内容页（supporting） | ≤ 35% | ≤ 22% | ≤ 5% | ≤ 22% |
| 数据高潮页（P02/P14/P20/P21） | ≤ 30% | ≤ 18% | 15–20% | 35–50% |

**色彩节奏**：强调色只在 P02（合计 +1219）、P05（三个真缺陷）、P06（中间插入 ❌）、
P10（协议真缺陷）、P11（粘住 [0,0]）、P14（9304 锚点）、P16（三类问题与遗留）、P17（未变红的灰条）、
P18（纪律出处）、P20（[0,0] 收窄）、P21（400 kW 目标线）、P23（734 元）、P24（阻塞项）出现；
其余页（尤其 4 个章节扉页）为 0，保证"红=值得停一下"的语义不被稀释。

### 2.2 渐变与半透明

- 允许：`linear-gradient(135deg, #3B82F6 0%, #06B6D4 100%)` 用于章节扉页色块与卡片头；
  `rgba(59,130,246,0.06)` 作大面积浅底（表格斑马、区间带）。
- 不使用多于一层的阴影；不在同一元素混用渐变 + 阴影。

| 层级 | 字号 | 字重 | 行高 | 用途 |

## 4. 信息密度门禁

- 内容页：正文 ≥ 180 字 / ≥ 1 主视觉或图表 / 留白 ≤ 22%
- 数据页：主图占 B 区 ≥ 50%，配 ≥ 1 句「所以呢」判断
- 封面 / 章节扉页 / 结束页：留白 40–60%，但留白必须围绕焦点元素
- 卡片填充率 ≥ 85%；横向兄弟卡三段（标题 / 正文 / 尾条）y 轴对齐
