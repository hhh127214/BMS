# 现场上线所需材料清单

> 目的：澄清一个已经确认的误解 —— **客户不是"只要上传点表"就能用**。
> 点表是"最难、最必需的一项"，但它只是上线链条中间的一环；真正的原始材料
> 在客户/厂家手里，部署侧还有两个动作，最后一步"连真机核对"不可省。
>
> 本文档把"客户要提供什么 / 我们在平台里填什么 / 部署时做什么"三件事分开写，
> 并如实列出三条**当前能力边界**，避免交接时把"能上传"说成"就能用"。

---

## 一、客户/厂家必须提供（不可替代）

这三样我们**替代不了**，缺一不可：

| # | 材料 | 用途 | 备注 |
| --- | --- | --- | --- |
| 1 | **厂家《Modbus 通信协议》手册** | 填点表的原始依据 | 手册是"厂家自己的地址规划"；点表是照着手册**翻译**出来的产物，不是原始材料 |
| 2 | **设备 IP / 端口 / 从站号** | 接入参数 | 现场问；IP 在设备铭牌或交换机上 |
| 3 | **铭牌额定功率 / 容量** | 台账 + 策略 + 报表 | PCS 额定功率、电池容量、变压器容量、需量目标 |

其余全是"照着填"。所以客户配合度可以压得很低：**给一份 PDF + 三个数字**，
剩下的填表、放文件、重启都由我们做。

---

## 二、平台里填三处（设备台账 → 接入参数 → 点表）

1. **设备台账**：设备号、类型、额定功率/容量（来自铭牌）。
2. **接入参数**：协议（Modbus TCP）、host、port、从站号、轮询周期、超时、启停。
3. **点表 CSV**：32 行（行序即索引），点名/表类型/地址/编码/字序/缩放/可写性。

点表模板：`13/docs/point_map_template.csv`。填表的三条硬规矩：

- **行序就是索引**，不能删行、换行；
- **`name` 列不能改**（它锚定点表身份）；
- **三个指令点**（P 电池 / 功率上界 / 功率下界）必须**同表 HR 且地址连续**——
  它们靠一次 FC16 原子下发，拆开会造出"新功率 + 旧权限区间"的中间态。

违反任意一条会被**当场拒绝，活动点表一个字节都不动**。

---

## 三、部署两个动作

1. **把点表放到约定路径**：`config/point-map/active.csv`（可用环境变量
   `EMS_POINT_MAP_DIR` 覆盖目录）。
2. **重启 13/**（或 07/ 现场进程）。点表是**启动时读一次**，没有热加载——
   改了点表必须重启才生效。

---

## 四、不可省的一步：连真机核对

`--plan` 只查"表本身合不合法"，**不发一个报文**。真正要看的是：

```
13\build\modbus_probe.exe --host <设备IP> --port 502 --unit <从站号> --load-map 点表.csv
```

盯最右边那列 `ok`。为什么不可省：**字序（`word_order`）和 scale 是厂家手册里
最常写不清的两列** —— 填反了**不会报错**，会安静地读出"看着合理但是错的"数，
这种错比直接连不上危险得多。

---

## 五、当前能力边界（如实记录）

| 边界 | 现状 | 说明 |
| --- | --- | --- |
| **仅 Modbus TCP** | 13/ 只有 `modbus_tcp_client.h` | 无 RTU / 串口实现；现场若是 485 接法，需先加 RTU 客户端 |
| **一次一台设备** | `ModbusDeviceIO` 是单份 `Config` | 现场 PCS + BMS + 电表三台 = 三个实例 + 三份点表 + 07/ 装配三层 |
| **现场入口已具备** | `07/src/main_field.cpp` | `--device sim\|rtdb\|modbus`（默认 sim），`--control` 真下发、`--record` 实录 |

---

## 六、完整上线动作（7 步）

1. 拿到厂家手册 + 三个数字（IP/端口/从站号、铭牌额定值）。
2. 平台填设备台账 + 接入参数。
3. 照手册翻译出点表 CSV，平台里保存（自动落盘到 `config/point-map/active.csv`）。
4. `modbus_probe.exe --load-map` 连真机核对，盯 `ok` 列，逐点确认字序/scale。
5. 只读巡检：`07\build\main_field.exe --device modbus --host <IP> --unit <n>` 看数据对不对。
6. 确认无误后加 `--control` 真下发；要留底加 `--record <csv>`，再 `14\scripts\import_live.bat` 入库看曲线。
7. 现场常驻：`--control --record` 由守护器拉起（19/ 的范围），实时数据持续进平台。
