## 2. 十一条最硬的不变式（全表见 skill §6/§11）

1. **Power 符号**：P_bat 放电正/充电负；P_grid 外购正/倒送负；P_load>0；P_pv>0。**无例外。**
2. **算法层看不见点名**，点名只在**适配器内部**。
3. **跨层不平均**（上层只收紧下层）；同层 `max(p_lower)`+`min(p_upper)`；desired clip 并标 `clamped`；
   On/Off 必须带**死区 + 滞环**。
4. `02/`=**设备侧**安全；`05/`=**系统级**统一器（全部安全源折成**一个** `(p_lower,p_upper)` 喂 `04/`）。
5. **ramp 只做后处理限速器**；**区间矛盾 → DERATED**（绝不锁 EMERGENCY）；抖动用 `Σ|Δcmd|`。
6. **关口功率只读电表**，不得三路相减（S05 防逆流 + 变压器过载都吃它）。
7. `execute()` 不做物理积分；**限值刷新用能力开关** `limits_are_live()`（`step()` 有 ⓪ 步）。
8. **点表只能追加在末尾**（索引 = 运行时坐标）；新点默认 **0=允许**。
9. **点区三个写入者互不重叠**：`RtDbPointWriter`→MEAS/STA/CFG、`RtDbDeviceIO`→CMD、
   **`RtDbExtWriter`→EXT**（A3.1）。**P3 网关纯只读 + 默认一律否定确认**。
10. **EXT 发布协议**：写者 `SEQ` **前后各递增一次**；读者要 `s0==s1` **且偶数**（「相等」挡快写者、
    「偶数」挡慢写者，**缺一不可**）；`clear_all()` **不归零**。
11. **失效兜底两条正交判据**：网关 `clear_all()`（快路径）+ EMS 侧 `now−EXT.TS>stale_s`（**不依赖进程
    活着**）。五个标志**不合并 bool**；时标来自未来必须判不可用；`stale_s<=0` = **禁用外部设定**。

## 3. ★★★ 铁律

- **先造出能区分对错的可观测差异，再谈修好**：正误写法**逐位相等**时任何断言都杀不死旧写法
  （「修了个寂寞」）→ **判据有效性必须自己反证一次**。
- **等价性可能被测对象自身的 bug 维持** → 先问「原来的等价是怎么来的」，别急着回滚。
- ★ **「注释/文案声称的行为」必须与代码实际行为一致**：承诺**要么有调用、要么有断言**。
  （已踩 4 次：`read_limits()`、`execute()`、网关心跳 `T+0s`、`present` 无条件 true）
- **补通路前先问「这条路上有几步是夹具替我做的」**：跨内存边界 + 夹具注入 = **测试盲区** →
  必须有一个**走真段、不注入任何东西**的测试 exe（A3.1 的 T73~T76）。
- **「没报违规」≠「查过之后没违规」**：并发/覆盖型用例要有守卫（`checked == usable_n`）。
- **「允许 SKIP」必须配一个「宣布自己 SKIP 了」的信号**，且一路传到**最外层结论行**。
- **默认值必须是实测跑出来的那个**；跨「我的环境 / 脚本的环境」的数字**必须用官方入口
  （`build_all.bat`）实测再写进文档**。**运行期产物落 `build/` 或 `logs/`，绝不落源码目录**。
