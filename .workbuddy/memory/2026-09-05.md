### 关键技术决策记录

1. **不抽 `IController` 抽象基类**：三控制器的 `update()` 签名（输入/输出维度差异过大）+ 嵌入式实时性 + 单文件头单元测试，三重因素共同否决了"抽象基类"。改抽 **共享工具**（`clamper.h`、`controller_types.h`），收益更直接
2. **共享 `clamp` 工具化**：从 AntiReverse（模板）、Smoothing（私有成员）、Demand（私有成员）、Integration（`clamp_double` 函数）四处实现统一收敛到 `03/shared/clamper.h` 的 `bms::clamp/clampf`
3. **三控制器集成改名 `integration`**：原目录名 `三控制器集成` 在 g++ `#include` 中遇到 → `Invalid argument`（MinGW 处理 GBK 路径包含），目录改英文名后跨目录头文件用 `-I` 注入，避开中文在 `#include "..."` 字面量里的限制
4. **复用单文件 main 复用模式**：02 模块用 `#define main safety_constraint_manager_main` 把 demo 与 test 共用 `.cpp` 翻译单元，避免 `src/safety_constraint_manager.cpp` 主函数和测试链接冲突
5. **MinGW `M_PI` 缺失**：`光伏出力平抑控制器/tests/main_smoothing_csv.cpp` 加 `#define _USE_MATH_DEFINES` 在 `<cmath>` 前
