## 规划中（未做）

`di_table.csv` —— 把 DI 表从代码里外置出来，格式拟为：

```csv
di,name,unit,bytes,decimals,sign_bit,note
02010100,A 相电压,V,2,1,0,
02030000,瞬时总有功功率,kW,3,4,1,带符号位
```

**为什么要外置**：附录 A.2 的"字节数 / 小数位 / 符号位"是三列独立信息，抄错一列
不会报错、只算出错数。现场换厂家就要改表，而改表不该要求重新编译。

**为什么现在没做**：本模块还没接 RtDb，点位仍是 CLI 命令行参数；
先有"点表要喂给谁"这个问题，外置格式才有约束。等 `Meter645DeviceIO` 落地时一起做。

加载器要参考 `17/src/point_table_loader.h` 的做法（UTF-8-BOM 容忍、
失败回退内置表、**加载失败要显式报错而不是静默用默认值**）。
