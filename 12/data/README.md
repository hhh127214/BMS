# 12/data/ — 验收数据目录

本目录**不放输入数据**：验收器的全部输入来自前面 11 个模块的公开出口与文件系统，
不需要任何外部数据文件（这是"验收可复现"的要求 —— 输入越少，环境依赖越少）。

本目录只放**产物**：

| 路径 | 来源 | 说明 |
|---|---|---|
| `_report_selftest/` | 检查项 **A7-06** | 验收器把自己的当前维度当作一个"微型报告"写入这里，验证 md / json / html 三个渲染器与落盘路径全部可用。**可以随时删除，下次运行会自动重建。** |

正式验收报告写到 `12/docs/ACCEPTANCE-REPORT.{md,json,html}`（放 `docs/` 是因为它是
交付文档的一部分，需要跟模块文档一起被 `A7-02` 检查到）。
